# AudiobookBay Enhancer

Userscript that gives audiobookbay.lu a modern card layout, infinite scroll,
filters (category, language, format, bitrate, Goodreads rating), direct
Goodreads links with ratings, and some Colophon-inspired themes.

## Install
1. Install Violentmonkey [https://violentmonkey.github.io/] or some other userscript manager.
2. Click **[Install script](https://raw.githubusercontent.com/Mhs11294/audiobookbay-enhancer/main/abb-enhancer.user.js)**
   and confirm in the dialog. Updates arrive automatically.

## Privacy
The script talks only to audiobookbay.lu and www.goodreads.com (public
autocomplete endpoint) to resolve book pages and ratings. Nothing is
sent anywhere else; lookups are cached locally in the userscript manager.
